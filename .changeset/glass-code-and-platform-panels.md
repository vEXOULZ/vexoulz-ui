Windows (`.vx-panel`) and platform-web panels (`platform.css`) are clear glass: no blur, a thin tint, a sheen and a lit top edge (new tokens `--vx-glass-clear`, `--vx-glass-sheen`, `--vx-glass-edge`), so the stars stay sharp behind them. Code blocks (`.vx-code`) are frosted glass like the buttons. Platform-web dialogs keep the near-opaque popup fill.
